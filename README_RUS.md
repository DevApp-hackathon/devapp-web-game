# DevOps Startup

Браузерная обучающая игра о DevOps, созданная на JavaScript и Phaser для хакатона School 21. Игрок исследует виртуальный офис, проходит задания и учится основным понятиям и практикам DevOps: работе с Git, CI/CD, сборке и деплою, мониторингу и командным процессам.

## Что сделано

- Создана игровая сцена с офисом и персонажами.
- Реализованы обучение, сюжетные задания, игровые ситуации и режим песочницы.
- Добавлены интерактивные материалы со справочником терминов и подсказками.
- Подготовлены игровые изображения и отдельные HTML-прототипы экранов.
- Настроены запуск и сборка проекта с Vite, а также автоматическая публикация через GitHub Actions.

## Как посмотреть игру

**Открыть игру онлайн:** [DevOps Startup на GitHub Pages](https://devapp-hackathon.github.io/devapp-web-game/)

Чтобы запустить локально, откройте папку `game` в терминале и выполните:

```bash
npm install
npm run dev
```

Затем откройте адрес, который Vite покажет в терминале (обычно `http://localhost:5173`).

## Структура проекта

- `game/` — исходный код игры, ресурсы, прототипы страниц и конфигурация сборки.
- `project-documents/` — концепт-документ и презентация проекта.
